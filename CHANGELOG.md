## [0.1.0] - 2026-10-05

### Added

- GitHub Actions workflow for Pull Request validation.
- Automatic Python package build.
- SHA-256 checksum generation for build artifacts.
- Upload of `.whl`, `.tar.gz`, and checksum files as GitHub Actions artifacts.
- Ruff static analysis as part of the CI pipeline.
- Composite GitHub Action for creating Git tags and GitHub Releases.
- Automatic release workflow triggered by changes merged into `main`.
- Project contribution and community documentation.
