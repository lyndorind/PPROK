# Security

If you discover a security vulnerability in this project, please do not create a public GitHub Issue.

Please report the vulnerability privately by email: **p.prokopenko.zk41.fbmi28@lll.kpi.ua**.

When reporting a vulnerability, please include:

- a description of the problem;
- steps to reproduce it;
- the possible impact;
- any additional information that may help investigate the issue.

The report will be reviewed as soon as possible.
