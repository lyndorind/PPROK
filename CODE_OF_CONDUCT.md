# Code of Conduct

## Our Pledge

We are committed to providing a respectful, friendly, and inclusive environment for everyone participating in the PPROK project.

All contributors are expected to communicate professionally and treat other participants with respect.

## Our Standards

Examples of acceptable behavior include:

- Respectful and constructive communication
- Giving and accepting helpful feedback
- Respecting different opinions and experiences
- Focusing on the project and its improvement
- Helping other contributors when possible

Examples of unacceptable behavior include:

- Insults, harassment, or personal attacks
- Offensive or discriminatory comments
- Threats or intimidation
- Sharing another person's private information without permission
- Deliberately disrupting Issues, Pull Requests, or Code Reviews

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues
- Pull Requests
- Code Reviews
- Discussions
- Other communication related to the project

## Enforcement

If you notice behavior that violates this Code of Conduct, please report it to the project maintainer.

Reports will be reviewed and handled appropriately.

Project maintainers may remove comments, reject contributions, or restrict participation when necessary.

## Responsibility

All contributors are responsible for following these rules and helping maintain a professional and respectful project environment.
