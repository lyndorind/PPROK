# Support

If you need help with the project, please create an Issue in this repository.

Before creating an Issue:

1. Check existing Issues to avoid duplicates.
2. Click **New issue**.
3. Add a clear and descriptive title.
4. Describe the problem or question.
5. Add steps to reproduce the problem, if applicable.
6. Add screenshots or error messages if necessary.
7. Submit the Issue.

Please provide enough information to make the problem easy to understand and reproduce.
